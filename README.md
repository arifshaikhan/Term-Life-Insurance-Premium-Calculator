# Term-Life-Insurance-Premium-Calculator
This project is built to learn the actuarial pricing basics using Excel & VBA.
It automates premium calculation using the user's age, gender, smoking status and payment mode. 
This calculator uses a simplified model compared to actuarial methods (e.g., EPV, qₓ survival models).
Rates are illustrative only (based on per 1,000 sum assured, by age/gender/smoker).
Users should start at the Inputs worksheet to put in the details and start calculating.
Final premium amount will be displayed in the Outputs worksheet.
